# Goal-Driven Execution (/goal)

1. **Define Verifiable Success Criteria First**: Before writing code, translate every user requirement into concrete, testable checks (e.g., LCP/image load timing, zero console errors, zero AI-slop anti-patterns, working interactive flows).
2. **Execute Surgically**: Implement the minimum essential code that satisfies all criteria without regressions.
3. **Empirically Verify**: Run automated checks, headless browser verification, and mechanical detectors until all criteria pass.
